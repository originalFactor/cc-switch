# 1.1 软件介绍

## 什么是 CC Switch

CC Switch 是一款跨平台桌面应用，专为使用 AI 工具的开发者设计。它帮助你统一管理 **Claude Code**、**Claude Desktop**、**Codex**、**Gemini CLI**、**Grok Build** 共 5 个工具的配置。

## 解决什么问题

在日常开发中，你可能会遇到这些痛点：

- **多供应商切换麻烦**：使用不同的 API 供应商（官方、中转服务商），需要手动修改配置文件
- **配置分散难管理**：每个工具都有自己的配置文件，格式各不相同（JSON、TOML、YAML、`.env` 等）
- **无法监控用量**：不知道 API 调用了多少次，花了多少钱
- **服务不稳定**：单一供应商出问题时，整个工作流中断

CC Switch 通过统一的界面解决这些问题。

## 核心功能

### 供应商管理
- 一键切换多个 API 供应商配置
- 支持预设模板，快速添加常用供应商
- 统一供应商功能，跨应用共享配置
- Claude Desktop 第三方供应商、直连模式与模型映射
- 用量查询与余额显示
- 端点速度测试

### 扩展功能
- **MCP 服务器**：管理 Model Context Protocol 服务器，扩展 AI 能力
- **Prompts**：管理系统提示词预设，快速切换不同场景
- **Skills**：安装和管理技能扩展
- **会话管理器**：浏览、搜索各工具的会话历史，复制恢复命令继续对话
- **授权中心**：集中管理 ChatGPT（Codex）、GitHub Copilot、xAI 等 OAuth 账号

### 连接模式、本地路由与高可用
- 三种连接模式：**直连**（客户端直接连供应商）、**路由**（请求经本机 CC Switch 转发）、**聚合**（Claude Code 和 Codex 专用，多家供应商的模型同列在 `/model` 里）
- 本地路由在 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses 和 Gemini Native 之间转换请求格式
- 自动故障转移，主供应商失败时自动切换备用
- 熔断器机制，防止频繁重试失败的供应商
- 详细的 Token 用量追踪与成本估算：不开本地路由时，也会从各工具的本地会话记录统计用量

## 支持的应用

| 应用 | 说明 | 供应商模式 |
|------|------|------------|
| **Claude Code** | Anthropic 官方的 AI 编程助手 | 切换 |
| **Claude Desktop** | Claude 桌面应用，支持官方登录与第三方 3P profile | 切换 |
| **Codex** | OpenAI 的代码生成工具 | 切换 |
| **Gemini CLI** | Google 的 AI 命令行工具 | 切换 |
| **Grok Build** | xAI 的 AI 编程命令行工具 | 切换 |

- **切换**：同一时间只启用一个供应商，切换时改写该工具的配置文件。

各工具支持哪些功能（本地路由、聚合、托盘切换、MCP、Skills、提示词、会话、用量统计）不尽相同，详见 [1.3 界面概览](./1.3-interface.md) 与各功能章节。

## 支持的平台

- **Windows** 10 及以上（x64 / ARM64）
- **macOS** 12 (Monterey) 及以上
- **Linux** x86_64 或 ARM64，需要 glibc 2.35+ 和 WebKitGTK 4.1，例如 Ubuntu 22.04+、Debian 12+ 及较新的 Fedora；RHEL / Rocky / Alma 8–9 暂不支持

## 技术架构

CC Switch 使用现代化的技术栈构建：

- **前端**：React 18 + TypeScript + Tailwind CSS
- **后端**：Tauri 2 + Rust
- **数据存储**：SQLite（供应商、MCP、Prompts）+ JSON（设备设置）

这种架构确保了：
- 跨平台一致的体验
- 原生级别的性能
- 安全的本地数据存储
